Assignment 8 Dashboard Prototype: NYC Subway Ridership and Arrest Patterns

This dashboard was created for EPPS 6356 Assignment 8, which asks students to develop a working dashboard prototype and a plan for the final team project.

The purpose of this prototype is to test the dashboard structure, visualizations, and interactive features using a manageable subset of the planned final-project data before expanding the analysis to a larger dataset.

Research Question

How do subway ridership and arrest patterns vary across stations and over time, and how do patterns change after accounting for passenger volume?

Data Sources
  • MTA Subway Hourly Ridership Data
  • NYPD Arrests Data

The MTA data provide information on subway ridership, station complexes, boroughs, and station locations. The NYPD data provide information on arrest dates, offense types, boroughs, and arrest locations.

Prototype Scope

For Assignment 8, the dashboard uses 2024 data for nine high-ridership subway station complexes in Manhattan, Queens, and Brooklyn.

A smaller group of stations is used in this prototype to make the first version of the dashboard manageable. The final project is planned to expand the analysis to the full subway network and the 2020–2024 period.

Unit of Analysis Station × month

Monthly subway ridership and arrest measures are calculated for each selected station complex.

Arrest Measure

NYPD arrests were assigned to the nearest selected subway station when the arrest occurred within 500 meters of that station.

This approach allows arrest activity near subway stations to be compared with passenger volume. The 500-meter distance rule is used for the Assignment 8 prototype and may be refined in the final project.

Key Measures
  • Monthly subway ridership
  • Monthly arrest count
  • Arrests per 100,000 riders
  • Station complex
  • Borough
  • Month

The ridership-adjusted arrest rate is calculated as:

Arrests per 100,000 riders = (Monthly arrests / Monthly ridership) × 100,000

This measure helps distinguish stations with high arrest counts because they serve many passengers from stations with relatively high arrest activity after passenger volume is taken into account.

Visualizations

The dashboard uses three chart types from Abela’s Chart Suggestions—A Thought-Starter:

  • Chart #6 — Line Chart: monthly change over time
  • Chart #9 — Scatter Chart: relationship between ridership and arrest rate
  • Chart #18 — Bubble Chart: relationship among arrest counts, arrest rates, and passenger volume

The dashboard also includes value boxes and an interactive station-level data table to summarize and compare the selected stations.

Interaction

Users can:

  • Hover over chart elements to view additional information
  • Use the time-series range selector to focus on specific periods
  • Search and sort the station-level data table
  • Compare raw arrest counts with ridership-adjusted arrest rates across stations

Additional filters and reactive features may be added as the dashboard is expanded in the next stage of the project.
