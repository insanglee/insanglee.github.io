## synergy report

Our team divided the chart development and documentation responsibilities between two members. 

Insang Lee was responsible for Chart 1, the variable-width column chart, Chart 3, the sorted bar chart comparing the top and bottom 20 countries, and the README with sessionInfo() information. 

Minyeong Yoon was responsible for Chart 2, the table with embedded charts, Chart 4, the column chart comparing regional mean HPI scores, and the synergy report. 

Both members used the 2025 observations from the same Happy Planet Index dataset. 

We took responsibility for their assigned tasks and contributed actively to the project. 

We each developed our charts and prepared our assigned documentation, sharing progress and making adjustments as needed to bring the work together. 

This balanced contribution helped us complete the project efficiently and work well as a team during limited time. 

All code, charts, and supporting documentation will be uploaded to the team’s GitHub repository.


When bringing our work together, we needed to align the variable names and regional classifications. 

Some initial code used renamed variables, while other code retained the original Excel column names. 

We revised the code to match the shared data structure and used consistent regional labels.

We also worked on titles, numeric labels, source notes, and chart formatting to make the results easier to interpret on the Quarto page. 


AI assisted with code explanations, troubleshooting, and design revisions. 

We documented this assistance in our prompt record at the bottom of assignment 4 document and revised the suggestions to fit our data and preferences. 

For example, revisions addressed missing table value labels, an unsupported caption argument, and colors that did not clearly communicate the chart’s main takeaway.


If we repeated this project, we would establish a shared data-preparation script process, naming convention, and visual theme colors before developing the charts separately. 

This would reduce integration work and help us maintain consistent formatting. 

We would also reserve more time for rendering the complete Quarto page from a clean R session and checking the final documentation together.
