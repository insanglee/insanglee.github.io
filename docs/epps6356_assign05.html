Part 2: ggplot2

library(ggplot2)

theme_mine <- function() {
  theme_minimal(
    base_size = 11,
    base_family = "sans"
  ) +
    theme(
      plot.title = element_text(face = "bold"),
      panel.grid.minor = element_blank(),
      plot.caption = element_text(hjust = 1)
    )
}

400% Zoom Comparison

I opened each exported file and compared the text and lines at 400% zoom.

PDF: The text and lines remained sharp and clear at 400% zoom.

SVG: The text and lines also remained sharp and clear at 400% zoom.

PNG: The image remained fairly clear, but some pixelation was visible around the text and lines at 400% zoom.

JPG: The text and lines appeared less sharp, with more noticeable pixelation at 400% zoom.

TIFF: The image quality remained high, but some pixelation was visible at 400% zoom because it is a raster format.

BMP: The text and lines also became pixelated at 400% zoom, although there were no noticeable compression artifacts.

Recommended Formats

For a journal article, I would use PDF because it is a vector format and remains sharp when resized.

For a web page, I would use SVG because it remains sharp at different screen sizes and works well for simple graphics.

For a PowerPoint slide, I would use PNG because it is widely supported and provides good image quality.

Reflection

Pie charts can be useful when there are only a few categories and the purpose is to show simple parts of a whole. Cleveland and McGill (1984) show that people compare positions and lengths more accurately than angles and areas. Because pie charts rely on angles and areas, they are not ideal when categories have similar values.

In my pie chart, there are only three cylinder categories, so the general differences are easy to see. However, the bar chart allows more precise comparison among the categories. Therefore, I would use a pie chart only when the number of categories is small and exact comparisons are not the main purpose.
