Scrape Five Pages

Code 
scrape_books_page <- function(page_number) {
  
  url <- paste0(
    "https://books.toscrape.com/catalogue/page-",
    page_number,
    ".html"
  )
  
  page <- read_html(url)
  
  tibble(
    title = page |>
      html_elements("article.product_pod h3 a") |>
      html_attr("title"),
    
    price = page |>
      html_elements(".price_color") |>
      html_text2() |>
      parse_number(),
    
    rating = page |>
      html_elements(".star-rating") |>
      html_attr("class") |>
      str_remove("star-rating "),
    
    page = page_number
  )
}

What Changed When the Target Changed?

Changing the target page meant that the original table index, column names, and table structure could no longer be assumed to work. I had to inspect the new page and identify the appropriate table and country-related column again because Wikipedia pages do not share a single fixed schema.

First, I clean the column names.

Next, I remove footnote markers and extra spaces from character variables.

Code 
forex_clean <- forex_clean |>
  mutate(
    across(
      where(is.character),
      ~ .x |>
        str_replace_all("\\[[0-9]+\\]", "") |>
        str_replace_all("\u2009", " ") |>
        str_squish()
    )
  )

The scraped table contains repeated header rows, so I remove them.

Code 
forex_clean <- forex_clean |>
  filter(
    country_as_recognized_by_the_un !=
      "Country(as recognized by the UN)"
  )

Remove Total or World Rows

Code 
forex_clean <- forex_clean |>
  filter(
    !if_any(
      everything(),
      ~ str_detect(
        as.character(.x),
        regex("^(Total|World)$", ignore_case = TRUE)
      )
    )
  )

Clean the Date Variable

The last_reporteddate variable was imported as character text, so I convert it to a standard date format.

forex_clean <- forex_clean |>

3. Fetch the Same Quantity from the World Bank API

The World Bank publishes total reserves, including gold, in current U.S. dollars under indicator FI.RES.TOTL.CD.

Code 
wdi_reserves <- WDI(
  country = "all",
  indicator = "FI.RES.TOTL.CD",
  start = 2024,
  end = 2024,
  extra = TRUE
)

wdi_reserves <- wdi_reserves |>
  select(
    country,
    iso2c,
    iso3c,
    year,
    reserves = FI.RES.TOTL.CD
  ) |>
  filter(
    !is.na(reserves),
    iso2c != ""
  )
